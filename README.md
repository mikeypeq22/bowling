# From Gutter to Glory v1.03

Browser bowling-center management game with two story campaigns.

## Play
- GitHub Pages: upload the **contents** of the v1.03 GitHub Pages ZIP to your existing hosting repository.
- Local standalone playable demo: `PLAYABLE_DEMO.html` (local browser save only).
- Keep your original Firebase Authentication and Firestore rules; this build contains the same configured Firebase client.

## v1.03 progression
- Build Lane 1 to meet Maya and play her First Frame challenge in **Bowlers**.
- Unlock Leo by finishing Maya’s frame, owning two lanes, and serving eight bowling groups.
- **Goals → Ratings** displays department reward targets.
- **Staff** has XP/5-level careers, specializations, wage expectations and concern conversations.
- In **The Back Alley**, build entrance security, then open **Goals → Story → Crew & Territory** for the Old Town encounter.
- Settings → Development Testing still offers a developed local-only preview.
